
# GSAP Animation Project

## 🚀 Project Overview

This is a modern and interactive web project built with **React.js and GSAP (GreenSock Animation Platform)**. The main focus of this project is creating smooth, engaging, and high-performance animations to improve the overall user experience.

The project demonstrates how GSAP can be integrated with React to create advanced animations, interactive elements, and smooth scrolling effects.

## ✨ Key Features & Technologies

* 🎨 **React.js** – Used to build the component-based user interface.
* ⚡ **GSAP** – Used to create smooth and high-performance animations.
* 📜 **ScrollTrigger** – Used for scroll-based animations and revealing elements while scrolling.
* 🎬 **GSAP Timeline** – Used to control and sequence multiple animations.
* 🖱️ **Hover Animations** – Added interactive animations on user interactions.
* ✍️ **Text Animations** – Created smooth text entrance and transition effects.
* 🔄 **Page/Section Transitions** – Implemented smooth transitions between different sections.
* 🌊 **Smooth Scroll Animations** – Added engaging animations based on the user's scroll position.
* 📱 **Responsive Design** – Designed the project to work across different screen sizes.
* 🧩 **Reusable React Components** – Structured the project using reusable and maintainable components.

## 🎯 Project Objective

The main objective of this project was to gain practical experience with **GSAP and advanced web animations** and understand how animation libraries can be integrated with React to create modern and interactive websites.

---

## 📚 What I Learned

Through this project, I learned how to:

* Create animations using GSAP.
* Use `gsap.to()`, `gsap.from()`, `gsap.fromTo()` and `gsap.set()`.
* Create animation sequences using GSAP Timeline.
* Implement scroll-based animations using ScrollTrigger.
* Create interactive hover animations.
* Control animation duration, delay, easing, and timing.
* Integrate GSAP animations with React components.
* Build smooth and engaging user interfaces.

---

## 💡 Conclusion

This project helped me improve my understanding of **GSAP, ScrollTrigger, Timeline, React.js, and modern web animations**. It also gave me practical experience in creating visually appealing and interactive web experiences.
